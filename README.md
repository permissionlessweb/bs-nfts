# BitSong NFTs

## Overview

This repository is a fork of the original [cw-nfts](https://github.com/CosmWasm/cw-nfts) project. The purpose of this fork is to provide additional functionality to the NFT collections created with this codebase.

## Compile & Optimize Contracts

To optimize the contract, ensure you have [just](https://github.com/casey/just) installed, the run:

```shell
just optimize
```

## Testing

```sh
# for unit test coverage:
cargo test
# for integration tests coverage, using our test-suite library:
cargo test -p test-suite
```
